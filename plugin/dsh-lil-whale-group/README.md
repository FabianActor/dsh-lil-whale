# @fabianactor/dsh-lil-whale-group（宿主侧）

小小肥鱼（lil-whale）鱼塘的**宿主侧** bundle：群聊、巡守、叫醒、睡眠、自主触发、单实例防护。

它不是一个独立插件——完整的一套（鱼塘目录、安装脚本、鱼的模板、体检）在仓库里：
https://github.com/FabianActor/dsh-lil-whale

只把它 `dsh plugin add` 进 profile，会得到一个空壳面板（没有鱼、没有家、没有巡守）。正确做法见仓库 README 的「装起来」。

配套的界面包：`@fabianactor/dsh-lil-whale-group-ui`。
