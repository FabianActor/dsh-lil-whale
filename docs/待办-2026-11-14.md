## 02:3x 包装壳卡住：根因与修法

| 项 | 结果 |
|---|---|
| 症状 | `up <鱼>` 在工具里卡住；鱼其实起来了、端口通，调用方等不到 EOF |
| 根因 | `Start-Process` 带重定向 ⇒ `bInheritHandles=TRUE` ⇒ 孙子进程继承调用方 stdout 管道 |
| 最小复现 | 嵌套起"活 45 秒"的隐藏进程 + 重定向 → 外层 47.3 秒；去掉重定向 → 1.5 秒 |
| 修法 | 双跳：无重定向启动器 → 带重定向起 dsh → 启动器秒退 |
| 实测 | `up fishball` 125s → **13.5s**；`down` 7.2s；重复 `up` 2s；3083 通、`session-mounted toolCount=34`、心跳 0 秒前 |
| 歪路（别重试） | `cmd /c ""…""` 吃掉重定向；WMI `Win32_Process.Create` 起长脚本静默不执行 |
