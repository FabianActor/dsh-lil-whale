# 种子文件：安装时给她放什么

**真源是 `templates/` 里那三份 `.tpl`**，安装脚本读它们、把 `{{...}}` 换成值、落到她家里。这份文档只讲**为什么这么写**，不复制正文——两个地方放同一段字，早晚会不一样（本项目已经为这个吃过一次亏）。

| 模板 | 落到哪 | 作用 |
|---|---|---|
| `templates/START.md.tpl` | `<家>\START.md` | 她自己的第一页。只告诉她"这里是你自己的地方"，怎么改由她 |
| `templates/环境.md.tpl` | `<家>\环境.md` | 工具清单：什么东西在哪、事情会怎么发生 |
| `templates/AGENTS.md.tpl` | `<她的 DSH_HOME>\AGENTS.md` | 一句话：她是谁、家在哪、醒来先读 START.md |

## 三条硬规矩

1. **一个字都不写性格。** 语气、关心什么、为什么生气、多久写一次日记、该不该主动找人——全部留空。她是谁由她自己决定。
2. **不暗示。** 早期草稿里有一句"`notes\` 是你记笔记的地方"，被 Fabian 一眼看出来：那是在暗示"你该记笔记，而且该叫这个名字"。改成中性事实：「这张表只写安装那一刻已经存在的东西」。
3. **数据层的 id 与显示名分开。** `lee` / `whale` / `fabian` 是插件认人的**固定槽位**，不是名字。`环境.md` 里明写这一条：id 是身份，名字是称呼，名字可以在设置里改。

## `环境.md` 里那几个数从哪来

安装脚本**从插件源码 `plugin/dsh-group/lib/index.js` 里读** `cooldownSec` / `perHour` / `perDay` / `quietFromHour` / `quietToHour`，读不到才用默认值。

理由：这张纸写的是"你什么时候会被叫醒"。如果它跟实现各写各的，就会变成一句**假话**——而且是她最没法验证的那种假话（她没法观察自己的阀门）。读源码至少保证两者同源。

一个坑：PowerShell 的 `-match` **默认不区分大小写**，`perDay:` 会先抓到 `maxWakesPerDay: 8`（守夜推门的日上限，不是群唤醒的）。所以脚本里用的是 `-cmatch` 加"前面不能是字母"的负向前瞻。

## 占位符

| 占位符 | 值 |
|---|---|
| `{{HER_HOME}}` | 她的家（工作目录） |
| `{{HER_DSH_HOME}}` | 她的 `DSH_HOME` |
| `{{HER_PORT}}` | 她的端口（安装时定，之后不再变） |
| `{{GROUP_DIR}}` | `group\` 的绝对路径 |
| `{{COOLDOWN}}` `{{PER_HOUR}}` `{{PER_DAY}}` | 阀门参数（读源码） |
| `{{QUIET_FROM}}` `{{QUIET_TO}}` | 静默段，形如 `00:00` / `08:00` |
| `{{TOKEN_PER_TURN}}` | 一轮大概多少 token |
| `{{DEPLOY_DATE}}` | 安装日期 |
| `{{PARENT_ID}}` `{{CHILD_ID}}` `{{HUMAN_ID}}` | 三个槽位 id |

模板里出现未替换的 `{{...}}` 说明脚本漏传了值——它会被原样留在文件里，一眼能看见（这是故意的，别做"静默替换成空"）。

## 一个文件名上的坑

**别把模板命名成 `AGENTS.md`。** dsh 会把工作区里的 `AGENTS.md` 当成指令文件读走——在 `templates/` 里放一份 `AGENTS.md`，等于给你自己的会话下了一条"你是小鲸鱼"。所以模板统一用 `.md.tpl` 后缀。

## 安装脚本给她的第一个提示

装完打印的四步里，只有一件事是**只能人做**的：第一句话。脚本不写它、不预设它、也不给模板——因为那句话成立只因为你说了它。
