> 一句话：**不用从头开发一套看视频插件。** 访问层已经有一份现成的（上游 MIT 的 `bilibili-mcp`，我们 vendored 在 `pool\mcp\bili\mcp_server.py`），现在缺的只是"解码视频、抽原分辨率帧"这一层——那是给现有 server **加一两个工具**，不是写新插件。

## 2. 现在缺什么（为什么"只能看三帧"）

1. **故事板分辨率固定 480×270**（B 站自带 `x/player/videoshot`），细节上限就在这儿。
2. **我们自己设了 `_FRAME_MAX = 6`**（`mcp_server.py:2041`），默认 `num=3`（`:2125`）。不是 B 站的上限。
3. **间隔固定**：故事板一块约 2–6 秒，10 分钟的视频是抽样，不是逐帧。
4. **多 P 视频只覆盖第 1P**（`:2130` 注释），返回里用 `covered_sec` / `pages` 标明。
5. **没有解码能力**：`ffmpeg` 不在 PATH，也没有装在任何地方。`mcp_server.py:943` 那段 ffmpeg 是上游"从本地视频文件截封面"用的，和在线看视频无关。

所以"更多视觉信息"的瓶颈不在帧数上限，而在**故事板本身是缩略图**。

## 3. 三条路线（推荐第 1 条，和第 2 条一起做）

### 路线 1：给现有 server 加"解码抽帧"工具（推荐）

- 装 `imageio-ffmpeg`（pip 进她 venv，约 25 MB，自带静态 ffmpeg，不动系统 PATH）。
- 新工具 `bili_grab(bvid, at=[秒…], width=1280)`：`video.Video.get_download_url(cid=…)` 拿 DASH 视频流 → ffmpeg `-ss <t> -i <url> -frames:v 1 -vf scale=<width>:-1` 抽帧。
- 优点：真·原分辨率（1080p），能看清人脸/字幕/角落；复用现有 MCP 通道，**不写新插件、不碰宿主**。
- 代价：每次调用要下几 MB 流量（B 站 CDN 支持 range），要记进账本和额度。

### 路线 2：九宫格打包（便宜，先做）

- 给 `bili_frames` 加 `grid` 参数（3 或 4 列），把 N 帧拼成一张图，每格角上标时间。
- 意义：一次看 9–16 帧，返回**一张图**；模型端会按最大边长缩放，比十几张分开省上下文。
- 同时把 `_FRAME_MAX` 6 → 12（`at` 也放宽到 12 个点）。对 40 秒的短片，12 帧几乎等于全看。

### 路线 3：整段下载 + 逐秒拼图 / OCR / ASR 对齐

- 信息量最大，但重（带宽、磁盘、时间），不建议日常用。留给"要精读某一条"的场景。

**不要做的事**：另写一个 MCP server（重复造轮子）；装整装插件 `dsh-bili-scroll`（那套是"替你刷 + 日报 + 投递"，不是"看"，而且带发评论/私信的能力，和只读边界冲突）。

## 4. 建议的验收判据（可复现）

1. 同一条视频 `num=6` 返回 6 张图、`num=12` 返回 12 张（`frames[].kb` 都 > 0）。
2. `grid=3` 返回**一张** 1440×810 的图，`frames` 里每格有 `want_sec` / `got_sec`。
3. `bili_grab` 在 `at=[12]` 返回宽度 1280 的图，图上的字幕能读清（拿一条有硬字幕的片子测）。
4. 每次调用在 `pool\state\bili\ledger.jsonl` 有一行；超过 80 次/天时返回 `今天看够了（80 次/天）` 而不是静默失败。
5. 白名单外的工具（`bili_reply`、`bili_login`）在 `tools/list` 里**不存在**，不是"调用时被拒"。
6. 失败要有 `reason`（网络/风控/无权限），不许空返回。

## 5. 别踩的坑（都是真踩过的）

1. **`apply-neutral-preset.mjs` 会重写 profile patch**：它把"标记之后"整段替换掉。fishball 的 MCP 块现在在 **L205**、标记在 **L29** —— 重跑一次就会把它切掉（已知的雷，暂时没动）。改挂载请走生成器 `--with-bili <鱼键>`，或先备份。
2. **故事板 `index` 偶发返回空（实测约 25%）**：服务端已用 `pvdata` 兜底（`:2069`），别删这段。
3. **多 P 只覆盖第 1P**：`covered_sec` 是按第 1P 算的，别拿它当全片时长。
4. **AI 字幕要登录**：不登录只有 480P、字幕可能没有。
5. **凭证位置是"脚本同目录"**（`mcp_server.py:50` `CRED_FILE = Path(__file__).parent / "bili_credential.json"`），不是 `$BILI_DUTY_HOME`。
6. **`ffmpeg` 不在 PATH**：装了 `imageio-ffmpeg` 就用 `imageio_ffmpeg.get_ffmpeg_exe()` 拿路径，别假设系统里有。
7. **MCP 子进程是鱼进程启动时拉起的**：改完 `mcp_server.py` 要重启那条鱼的进程（`fish.ps1 down <键> -Yes` + `up <键> -NoBrowser`），不是刷新页面。
8. **白名单在服务端执行**（`@tool()` 装饰器里，`:54-76`），不是在提示词里说"别用"——名单外的工具连列表都不出现，这是真闸门。
9. **改 profile patch 前先停进程**（A.20），否则热重载会把正在跑的 agent 工具绑定抽走。
