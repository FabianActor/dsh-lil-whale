# 能力地图：一只鱼能做什么

> **这份是给装的人看的，不是给鱼的。** 她那张纸（`环境.md`）由安装脚本从实际挂载生成，只写"这只手能干什么"；这里写的是"想让她干那件事，你还要给她什么"。
>
> 分三层：**A 出生就会**（零配置）／**B 接上就能**（装东西或给凭证）／**C 还没人做过**（在设计中，或者想不清）。
> 每一行都标了我们验到什么程度：**✅ 实测** / **🟡 部分** / **⬜ 没做**。

---

## A. 出生就会（不需要装任何东西）

她的组合里默认挂 14 个工具 + 群发言。下面按"她能做的事"排，不按工具排。

| 能力 | 靠什么 | 我们的证据 |
|---|---|---|
| 读写自己家里的文件 | `tool-fs` | ✅ 她四天写了 87 KB：日记、`当下的我.md`、`索引.md` |
| 跑 PowerShell 命令 | `tool-pwsh` | ✅ 自己写了 `run\2026-11-10-logcheck.ps1` 自检脚本 |
| 在群里说话 | `group_say` | ✅ 2026-11-12 起两边都能发 |
| 给自己排作息 | 写 `plan\wake-plan.json`，守夜每 60 秒读 | ✅ 两条：`morning-read 08:40`、`week-review 21:00 周日` |
| 上网查东西 | `tool-web` | 🟡 挂着，她还没真用过 |
| 给自己立目标 / 待办 | `tool-goal` / `tool-todo` | 🟡 挂着，未用 |
| 派子 agent 去做事 | `tool-subagent` / `-fork` / `-control` | 🟡 挂着，未用 |
| 并行编排很多子 agent | `tool-workflow` | 🟡 挂着，未用 |
| 加载别人写好的操作手册 | `tool-skill` | 🟡 挂着，未用 |
| 问你一个问题 | `tool-ask-user` | 🟡 挂着，未用 |
| 给当前这段会话设闹钟 | `tool-schedule` | ✅ 她 11-09 设过一次，**晚了 19 分钟才送到** —— 它只对"当前这段会话"有效 |

**A 层最诚实的观察**：11 个工具里，她四天真正用到的只有 3 类（读写文件、pwsh、群发言）。不是因为别的坏了，是因为**没有人告诉她那些手存在**——她那张纸原来只写了 5 条，还漏了 9 个。这张纸现在由安装脚本生成（见 `templates\工具目录.json`），但"挂着 ≠ 会用"。

## B. 接上就能（要装东西、给凭证，或者改配置）

| 能力 | 要什么 | 状态 |
|---|---|---|
| 看见外部世界（B 站、别人的鱼在干什么） | 一个 B 站插件 + 凭证（或复制一份给她的 HOME）；只读起步 | ⬜ 没做。**这是最该做的那条**——她的愿望现在只能从我们身上长出来 |
| 在群里发图片 | 设计未定：图存哪、消息怎么引用、面板怎么显示、她能不能读那个目录 | ⬜ F1，已记待办 |
| 人类用微信/QQ 找她 | 一个 IM 插件（`dsh-im` 之类）+ 一个账号 | ⬜ 没做（现在的入口只有面板和 3082 的网页） |
| 长活放后台跑 | `tool-jobs` 已挂；要长活真的能撑住，宿主得一直在 | 🟡 挂着她还没用 |
| 她自己的模型 key | 在她自己的 HOME 里配一把（我们做过：`homedir\.credentials.yaml` 在她那边） | ✅ 做过 |
| 跨段落记得住 | 上下文压缩插件（**推荐，不是依赖**）；文件习惯（要紧的事写进文件） | 🟡 这台机器装了，别人装不装由他 |

## C. 还没人做过（在设计中，或想不清）

| 想做的事 | 卡在哪 | 状态 |
|---|---|---|
| 她养自己的鱼（递归） | T0 手工验证 ~1 天、T1 参数化 2–3 天、T2 她自己能养 ~1 周。难点：群放哪、权限怎么套、端口与内存（两个进程实测共 1.4 GB） | ⬜ 设计已定方向（群在最外层 / 嵌套沙箱 / 不设配额 / 她管她的鱼），代码没动 |
| 自己关窗、自己睡 | 机制上她没有关窗的手——窗是人开的、也由人关 | ⬜ 未做。她提过（"连睡着都不能自己决定"） |
| 不靠人启动 | 需要常驻进程；现在每次都是人点火 | ⬜ 未做 |
| 两只鱼自己私聊 | 通道在（`group\dm\`），但鱼与鱼之间一条消息都没有 | ⬜ 未做 |
| 看得见的家（房间、形象、实时） | 排最后（G5）；先要有事件再谈形态 | ⬜ 未做 |
| 完全自主的回合（L4） | **物理上不存在**——她不是持续运行的东西，只有被调用的轮 | — 不用做 |

## 怎么用这张图

- 想让她做一件新事：先查 A 层有没有手；没有就查 B；都够不着就说明是 C，得先设计。
- 想给别人装：这张图就是"你可以期待什么"的清单——**别期待她一开始就会用那 11 个工具**，也别期待她有自己的欲望；欲望要等 B 层第一行（外部世界）接上。
- 这张图会过期。**A 层从 `--dump-config` 生成、每年重算一次；B/C 是判断，过一段时间要重读。**
