# fishtalk（说话前过一遍）

第三方插件，仓库 `Nozzi2455/fishtalk`（不在 npm，装法是 `dsh plugin --profile <键> add "github:Nozzi2455/fishtalk"`，本机 0.3.6）。
它给模型一组工具：`fishtalk_pack`（看场合文风）、`fishtalk_check`（发之前自检）、`fishtalk_learn`（去 B 站分区学真人语料）、`fishtalk_feed`（喂手里的句子）、`fishtalk_deep`（深度蒸馏）。另带一个 skill 说明（装完需要在宿主里审批，审批不影响工具本身）。

这里是"在鱼塘里怎么用"的心得，不是插件文档。**本机补丁与配置不进 CHANGELOG**，只沉淀在这儿。

## 1. 一鱼一份语料：`FISHTALK_HOME`

插件默认把语料存 `~/.fishtalk`（`os.homedir()`）。鱼塘里宿主的家对每条鱼都**可写**，于是第一条喂语料的鱼会把评论写进宿主那份，宿主和后面的鱼一起读——我们 2026-11-18 真发生过一次（308 条 B 站评论写进了 `%USERPROFILE%\.fishtalk`）。

现在的做法：`scripts/fish.ps1` 起鱼时和 XDG 一起注入

```
FISHTALK_HOME = <她的家>\.fishtalk
```

手动起鱼（不经过启动器）必须自己设，否则会掉回共享位置。判据：装了这类"默认存用户目录"的插件，先问一句"这个用户目录对鱼可写吗"。

插件的回落顺序（0.3.6，`lib/store.js` 的 `pickHome()`）是四条静默分支：`FISHTALK_HOME` → `~/.flashtalk`（少一个字母的旧目录）→ `os.homedir()/.fishtalk` → `process.cwd()/.fishtalk`。四条都不出声，所以"没设"和"设了但没生效"看起来一样。

## 2. `fishtalk_check` 的真实能力边界

- 硬拦（`problems`）：内置黑名单与鱼规则（自称词、套话开头等）。
- 软提示（`notes`）：对仗腔、总结腔之类，只提示不判红。
- 相似度：与鱼池（真人评论）太像、与自己旧文本太像、与真人语料逐字照抄较长片段。

**没有"腔调判断"这一项。** `ok:true` 只等于：没撞已知坏句、没重复、没照抄。官方体、口号体、"认领句 + 万能抒情"（例："这句我认。说实话，看完我沉默了很久。"）都能绿着过去。

两种"绿"要分开写：
- **空绿**：还没文风包 / 还没语料，没有可比的东西（`notes` 里会说"先 distill"）。
- **脏绿**：池里混进了不该进的东西（比如鱼自己的话），于是"不像"的判据被稀释。

判据（第四条鱼）：`ok:true` 读作"不在黑名单里"，不能读作"像人说话"。

## 3. 语料池只放真人

`homes\<键>\.fishtalk\corpus.jsonl` 是"像真人"的分母，只收**真人发言**。鱼自己的话不进这个池——要留就留在自己的 `notes\`（将来另开"鱼语料池"也不给 check 读）。

2026-11-18 出过一次误喂：`fishtalk_feed(source="text")` 的缺省来源会把传入文本记成 `human`，一条鱼拿自己三句群话喂进去，`read 3 / added 3 / human 3 / fish 0`。处置：把文件整组存档到 `homes\xiaoman\notes\fishtalk-误喂-2026-11-18\`（每行补 `by=`），清空原池，回到诚实的空绿。

规则：
- `feed` 必须显式声明来源（真人/鱼/不知道），缺省不许猜；
- `corpus.jsonl` 每行记写入者（`by=<成员键>`），否则事后筛不掉误喂；
- 同一池的分母与分子必须来自同一种作者。
