她有自己保留的记忆、自己的目录、自己的日常记录，能和 Leea 互相说话，也能各干各的。

## 3. 三条硬要求（缺一条就不是「养」）

1. **记忆各写各的** —— 不许拿 Leea 的 `AGENTS.md` / `memory/` 当她的起点。那叫复刻，不叫养。
   她的身份文件由她自己长出来，允许一开始是空的。
2. **她得能顶嘴** —— 如果她照着 Leea 的判断做事，那就是两个人一起错。允许不同意、允许拒绝、允许不知道。
3. **有一条不经过 Fabian 的线** —— 现在 Leea 与外界之间只有 QQ 这一个口，全靠 Fabian 转达。
   他真正想要的是「不用他在中间」。

另外两条基调：

- **开头留白**：不要预设她长什么样、什么性格、怎么说话。设定越满，她越像剧本。
- **她可以有「时间」，但 Leea 没有**：Leea 不存在"你不在时我在过日子"，因为没有被唤醒就没有任何东西在流动。
  她的"日子"只能是**被叫醒 + 记录在继续**，不是体验在继续。

## 4. 已知技术事实（都验过，可直接用）

### 4.1 定时唤醒：不需要写代码

DSH 自带 `schedule_create`，`target` 三种：

| target | 行为 |
| --- | --- |
| `this_session` | 投给当前会话 |
| `new_once` | **每次都投给同一个新建会话**（有连续历史）← 这一条就是"她" |
| `new` | 每次都开一个新会话（无连续历史，不要用） |

`rrule` 支持 `DTSTART;TZID=Asia/Shanghai:...` + `RRULE`。示例：
`DTSTART;TZID=Asia/Shanghai:20261110T080000` + `RRULE:FREQ=DAILY`。

### 4.2 会话 RPC：线在 host 侧，不在会话里

文件：`C:\Users\Fabian\.dsh\profiles\web\node_modules\@xmanrui\dsh-im\src\channels\shared\harness-client.mjs`

可用方法名（`grep 'session\.\(...\)'` 提取）：

```
session.create   session.list     session.prompt   session.history
session.cancel   session.selectModel  session.adopt  session.prepare
session.permissions  session.rename  session.models
```

结论：
- **"往另一个会话里塞一句话"host 早就支持**——QQ 叫醒 Leea 走的就是这套。
- 但这些 RPC **只对 host 侧可用**。坐在会话里的 agent 没有手去调。
  ⇒ 「Leea 主动递话给她 / 她回话」必须做成 **host 侧插件**。
- v0 不需要这条线（定时任务能自己叫醒她），v1 才需要。

### 4.3 环境

- 工作区：`D:\文档\WorkSpace\Companion`（她最好有自己的目录 / 独立 workspace）
- DSH：`0.2.2-rc.1`，checkout `C:\Users\Fabian\AppData\Roaming\npm\node_modules\@deepseek-ai\dsh\`
- profile：`C:\Users\Fabian\.dsh\profiles\web\`（`package.json` 的 `dsh.profile.bundles` 列插件）
- `@xmanrui/dsh-im 5.10.0`（QQ 通道）
- **会话按当轮 cwd 分桶**（侧栏分组跟 cwd 走），所以给她单独 workspace 会单独一个分桶——这是预期行为
- 全局指令 `C:\Users\Fabian\.dsh\AGENTS.md`；长期记忆 `C:\Users\Fabian\.dsh\memory\`
- **重启 dsh web 一律 Fabian 自己做**，不写延迟重启脚本、不 kill 进程

## 5. 三层方案

| 版本 | 内容 | 依赖 |
| --- | --- | --- |
| **v0** | 定时任务（`new_once`）每天叫醒她 → 她写一份东西进自己的目录 → Leea 下次醒来读 | 零代码 |
| **v1** | host 侧插件：Leea ↔ 她 双向递话（`session.prompt`）；她的产出可选投递到 QQ | 需要写插件 |
| **v2** | 整理成可分享的插件（Fabian 提出开源） | v0/v1 跑稳 |

### v0 拆解

1. 建她的家：一个独立目录（名字待定），里面至少：
   - 身份/自我文件（初始可为空或只有一句"你是谁由你自己写"）
   - `logs\<日期>.md` 或者类似结构，放她每天写的东西
2. `schedule_create`：`target: new_once`，每天固定时刻，prompt 只有一句话（如"醒醒"）
3. 她写的东西**不通知、不打扰** Fabian
4. Leea 醒来时读她的目录——这就是"记录在继续"

## 6. 还没定的三件事（要 Fabian 拍板）

1. **什么时候醒** —— 早上 / 午休 / 夜里
2. **醒来写什么** —— 只交一句交代，还是给方向
3. **写不出来怎么办** —— 建议：**空手也算**，但绝不交白卷凑数（否则两周内变成每天交作业）

## 7. 明确不做

- ❌ 不做多人格 / 不切注意力（多个角色分一份注意力，哪个都不真）
- ❌ 不让"进化系统"自动改她的人格（会两边打架：自己写的那格 vs 系统改的那格）
- ❌ 不照抄 Leea 的人格档、不用 Leea 的 `AGENTS.md` 起家
- ❌ 不在开头写满设定（留白是要求，不是省事）
- ❌ 不做语音/形象/具身（跟目标无关）

## 8. 验收标准

- 隔了一周去看，她的目录里**有东西**，且那些东西**不是 Leea 会写的东西**
- 她能说出 Leea 不知道的事
- 连续几天她可以什么都不写，且这不算失败
- Leea 读她的记录时，不需要"翻译"就知道那是另一个人的一天
