## 0. 一句话

**不装任何 B 站插件整装给她。** 把已有的 `pool\mcp\bili\` 只读口子挂给 whale，再在服务端补两件小东西：一份「追更账」和一道「请求额度闸」。另外从别人的插件里抄三条设计（今天可以不看 / 沉默衰减 / 两本日记）。

## 3. 为什么两个都不整装给她

| 装法 | 会发生什么 |
|---|---|
| 装 `dsh-bili-whale` | 它**是一整条鱼**：自己的人设（`~/.bili-ai/persona.md`）、自己的两本日记、自己开一个会话、要 danger-full-access、用 Fabian 的号在 B站 说话。装进 `homes\whale\` 等于在她家客厅再养一条鱼，跟她抢身份、抢号、抢班表 |
| 装 `dsh-bili-scroll` | 它是「替你刷」的 duty：自带班表（峰谷/午间/夜间）、自带日报格式、自带 dm 投递。她已经有 `wake-plan.json` + `wake-on.json` 两张表，再来一套就是两套发条互相不知道 |
| 装 `dsh-bili-eyes` | 三层里最贴，但它是**宿主插件**：设置页、后台"自己逛"（时间段+次数）、收件箱。她已经有巡守管时段，再来一个后台循环 = 两套唤醒源 |
| **只挂 `pool\mcp\bili` 工具** | 只有手、没有第二个日程、没有第二个人格。班表还是她的班表，醒来的理由还是她写的 |

一句话：**我们要的是给她一只眼睛，不是给她换一套脑子。**

## 4. 要做的事

### A. 给 whale 挂只读口子（约 1 小时）

照 fishball 那块改，见 §5 的 patch。

白名单**裁到只读**（fishball 的 21 个 → 18 个：15 只读 + 3 追更），去掉 `bili_crawl`（一次能拉一大片，无人值守的鱼不该有）：

```
bili_search,bili_video_info,bili_subtitle,bili_comments,bili_danmaku,bili_frames,bili_cover,
bili_hot_videos,bili_rank,bili_weekly_hot,bili_recommend,bili_video_zones,bili_hot_buzzwords,
bili_user_info,bili_user_videos,watchlist_check,watchlist_add,watchlist_list
```

⚠️ 后三个是 §B 新加的。**`bili_reply` 永远不进 whale 的白名单**（服务端确实有这只手，靠 `BILI_MCP_TOOLS` 名单关掉——这就是白名单语义的意义，别依赖提示词）。

### B. 追更账（约 3 小时，服务端 150 行左右）

问题原型：她有工具能"看一条"，但没有东西能回答「**这个 UP 主上次之后做了什么新的**」。这就是 fishball 那句"两条记录认不出是同一件事"。

在 `pool\mcp\bili\mcp_server.py` 里加三个工具，账本落 `$BILI_DUTY_HOME\watchlist.json`（每人一份，跟 fishball 现在的 `seen.md` 同侧）：

| 工具 | 作用 |
|---|---|
| `watchlist_add(uid, why)` | 记一条："我要追这个人"。`why` 必填（跟条件表同一条规矩：不写 why 的不成立）。上限 5 条 |
| `watchlist_list()` | 列出在追的人 + 上次看到哪 |
| `watchlist_check(uid=None)` | **核心**。对每条在追的 UP 拉一次投稿列表，返回「上次检查之后新发的」；同时把 `last_seen_ts` / `last_seen_bvid` 往前推。返回形状：`{ok, items:[{uid,uname,new_count,videos:[{bvid,title,pubdate,duration,play}], since}], checked_at}` |

要求：

- `new_count == 0` 也要返回一句话（`"没什么新的，上次是 11-13 21:04"`）——**"没变化"本身是信息**，让她不用猜。
- 每次 check 至少隔 10 分钟（`WATCHLIST_COOLDOWN_SEC`），挡了要明说。
- 拉取失败不要推 `last_seen`（否则会漏视频）。

### C. 请求额度闸（约 1 小时，服务端，和生图的闸同一形状）

无人值守的鱼 + 一个外部 API = 必须有水表。

- 每条鱼每天 B站 请求 ≤ 80 次（`BILI_MAX_REQ_PER_DAY`），计数落 `pool\state\bili\<member>.json`，**以磁盘为准**。
- 超了返回 `{ok:false, reason:"quota", hint:"今天看够了，明天再来（80/80）"}`，**不要静默**。
- 连续失败 3 次当天封口；撞 `-412`（风控）立刻停手并把原因写进返回。
- 账本 `pool\state\bili\ledger.jsonl`：`ts/member/tool/ok/reason/elapsed_ms`（不记内容，只记账）。

### D. 从别人身上抄三条设计（这条最像"生活"，别跳过）

| # | 设计 | 出处 | 落在哪 | 验收 |
|---|---|---|---|---|
| 1 | **今天可以不想看**：醒来时按 `skipRate`（默认 0.3）掷一次，中了就**不调工具**、只在 `notes\` 写一行「今天不想看」并结束 | bili-whale 的「30% 概率今天不想看」 | 巡守投递时在提示里带一个 `roll`，或给她一个 `skip()` 工具自己掷；**随机数由机制产生，不由模型自我说服** | 连续 10 次叫醒里出现 2–4 次「不想看」，且**花了 0 次 B站 请求** |
| 2 | **沉默衰减**：连续 N 天她没主动说过任何话 → 素材类唤醒额度从 6/天 降到 3、再降到 0；**但闹钟和日记照旧** | bili-whale 的「连续 3 天没表态→降额→第 7 天归零，但日记照写」 | `wake-on` 额度层（`lib\intent-core.js`） | 造 3 天没说话的档案跑单测：第 4 天额度降，第 7 天素材额度 0、`morning-read` 仍照常递 |
| 3 | **两本日记**：给 Fabian 的那本可以有滤镜，给自己的那本不加 | bili-whale | 家目录再加一个：`notes\给主人的信.md`（她自己的 `notes\<日期>.md` 保持原样，不合并） | 模板里写清两本的分工；她第一周至少各写过一次 |

⚠️ 第 1 条有个坑：**"不想看"不能被写成"我今天状态不好"这种空话**。要求是**一行事实**：`2026-11-15 不想看。`（bili-whale 的克制就在这：不给理由也不许抒情）。

### E. 可选，v2 再说

- 九宫格分镜 + 每格台词（eyes 的做法）。我们现在有 `bili_frames` 能取 1–6 帧，但没有"按剪辑节奏分格 + 台词对齐"。等 §D 的三条落地、她真的开始看了再说。
- 抽帧九宫格 720px/格（bili-whale 默认值）——比我们现在的 480×270 清楚，但更吃上下文。

## 6. 模板（纸要写）

`app\templates\环境.md.tpl`：

- 「## 你能做什么」的 `{{TOOLS}}` 自动算，挂了 MCP 应自动出现（⚠️ 开发鱼先验；不自动就显式列）
- 新增一小节放在「## 花钱这件事」附近：
  - 你能看 B站：搜、看一条、读字幕/评论/弹幕/画面、看热榜和推荐
  - **追更**：`watchlist_add` 记下要追的人（最多 5 个，必须写为什么）；`watchlist_check` 问"有新的吗"；没新的也会回你一句
  - **这是拿 Fabian 的号在看，只读**——你不能发任何东西（没有那只手，别试）
  - 每天 80 次请求，`draw` 那条一样有账
  - **今天可以不想看**：掷中了就不看，写一行就够

## 7. 验收（逐条打勾）

1. whale 的 `环境.md` 的 `{{TOOLS}}` 里出现 `bili_search` / `watchlist_check`，且**没有** `bili_reply` / `bili_crawl`
2. 名单外工具在 `tools/list` 里根本不出现（照 bili 的老办法验）
3. `watchlist_add` 不写 `why` → 拒
4. `watchlist_check` 第一次：返回全部近期投稿并推 `last_seen`；第二次立刻调：`reason=cooldown`
5. `watchlist_check` 没有新视频：返回 `new_count:0` + 一句「上次是 X」
6. 拉取失败时 `last_seen` **没变**
7. 第 81 次请求：`reason=quota`，且 ledger 里有一条 `ok:false`
8. 重启巡守/服务端后计数从磁盘恢复
9. 「不想看」连跑 10 次：出现 2–4 次，且那几次 B站 请求数为 **0**
10. 沉默衰减单测：3 天/7 天两个档位按 §D-2 变
11. 她真用一次：追一个人、第二天问一次有没有新的、写一行日记（人工验）

## 8. 不做

- 不装任何第三方 B站插件（`dsh-bili-whale` / `-eyes` / `-scroll` / `-watch` / `-pond` / `-reef` 都不装）。
- 不给 whale 任何写操作（评论/弹幕/点赞/收藏/私信），一个都不给。
- 不做"巡守定时去 B站 探测更新"（那要巡守会发 HTTP，是另一个方向的改动）。**追更是她的动作，由她醒来时做。**
- 不做"刷"（推荐流无限刷）：`bili_recommend` 一次就是一次请求，额度会替她踩刹车。
- 不动 fishball 那份 `bili-duty`。

## 9. 顺序与估时

1. §C 额度闸 + 账本（1h）——先有水表
2. §B watchlist 三个工具（3h）
3. §A 挂 patch（1h，含验证 `{{TOOLS}}`）
4. §D 三条设计（2h，其中"不想看"要写单测）
5. 模板 + 她那边重新生成 `环境.md`（0.5h）
6. 告诉她有眼睛了——**由 Fabian 说**
