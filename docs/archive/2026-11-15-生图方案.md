# 生图方案（2026-11-15）

> 一句话：装 `dsh-ark-image`（42 KB、零依赖、一个工具、不需要界面），默认 `doubao-seedream-5-0-lite`（¥0.22/张，不分尺寸），宿主 只出一次力——火山方舟一把 key + 充 ¥50。插件**没有额度硬闸**，先用"唤醒预算 + 软账本 + 纸上的 3 张/天"跑一周，超支再上自研薄 MCP（施工图已有：`生图-需求.md`）。

---

## 〇、先说结论

1. **通道：装现成插件，不自己写。** `dsh-ark-image` 0.1.10（MIT，42,205 B，8 个文件，零运行时依赖，无构建脚本，**没有 client 半截**——无人值守的鱼能用）。它只做一件事：一个工具 `ark_generate_image`，把图下载下来按日期分目录存进工作区，同时在对话里显示。这正是我们要的，不多不少。
2. **模型：默认 lite，贵的那档留给她自己挑。** `doubao-seedream-5-0-lite-260128` ¥0.22/张**不分尺寸**（1K/2K/3K/4K 同价）→ 便宜到可以乱画。想认真画一张时她可以自己指定 `doubao-seedream-5-0-pro-260628`（¥0.3/张 ≤236 万像素；**2K 会到 ¥0.6**，所以用 pro 必须同时把尺寸降到 1K）。
3. **额度：这版没有硬闸，诚实写在纸上。** 插件不认"每鱼每天几张"，也不会拦。这一版的闸是现成的两样：她一天最多被唤醒 6 次（条件表全池 6/天、单条 2/天），加上纸上一句"一天 3 张"。真正的硬闸要靠自研 MCP，建议**先跑一周看账单**，触发条件见 §七。

## 一、为什么不是生态里那几个（选型）

| 包 | 月下载 | 体积 / 依赖 | 形态 | 判 |
|---|---|---|---|---|

| `dsh-image-gen` | 80,903 | 37.8 MB / 146 文件 / React + tldraw | 8 个 provider、图库、画布、侧边栏、设置页 | ❌ 她没窗口，37MB 全用不上 |

| `dsh-comfyui-workbench` / `dsh-comfyui-image` | 2,944 / 1,892 | — | 本地 ComfyUI（0 元/张） | ❌ 要常驻 GPU + 6–10 GB 模型；无人值守不稳 |
| `dsh-image-generation` / `-lite` / `-forge` / `-plugins` / `kkj-luna-...-bridge` | 3.3k / 2k / 0.9k / 2.5k / 2k | — | 设置页 + 侧边栏工作台 | ❌ 都需要界面 |

**为什么这次是"装别人的"，和 11-15 早上 B 站那次结论一致**：插件替我们写的是 HTTP + 落盘 + 尺寸/模型编码 + 错误处理，那些正是容易写错又没意思的部分；自研省不了多少，却要自己维护。

**为什么仍然保留自研这条路**：插件恰恰缺了无人值守最要紧的那块——**每鱼每日额度 + 水表 + 连败封口**。真需要硬闸时，施工图是昨天那份 `生图-需求.md`（工具口径、闸的数值、两本账位置、mock、验收 10 条都在），只需要把 API 那 40 行换成照抄 `dsh-ark-image` 的 `index.js`（24 KB，一文件可通读）。

## 四、宿主 要做的事（约 10 分钟）

2. 左侧「**开通管理**」→ 找到 **Doubao-Seedream** → 开通 **5.0 Lite**（想让她能认真画一张，就把 **5.0 Pro** 一起开）。

   - 为什么单独放：她的 `homes\whale\` 是可读的；key 不写进 patch、不写进她的家、不进 git（`pool\secrets\` 加 `.gitignore`）。

## 五、开发鱼要做的事（约 2 小时）

### 5.1 装插件（改两个文件，别用界面）

`homes\whale\dsh-home\profiles\whale\package.json`：

```json
{
  "dependencies": {
    "@fabianactor/dsh-lil-whale-group": "link:...",
    "dsh-bili-eyes": "0.8.3",
    "dsh-ark-image": "0.1.10"
  },
  "dsh": { "profile": { "bundles": [ "...", "dsh-bili-eyes", "dsh-ark-image" ] } }
}
```

`homes\whale\dsh-home\profiles\whale\cordis.patch.yml`——**必须插在 `# ---- 以下由 scripts/apply-neutral-preset.mjs 追加 ----` 这一行之前**（那个脚本每次会把标记之后的整段切掉重写，这是 11-14 踩过的坑）：

```yaml
- insert:
    - id: ark-image
      name: dsh-ark-image
      config:
        baseUrl: https://ark.cn-beijing.volces.com/api/v3
        model: doubao-seedream-5-0-lite-260128
        outputDir: <鱼塘根>\homes\whale\notes\画
        timeoutMs: 180000
        apiKey: ''            # 留空 → 读环境变量 ARK_API_KEY
```

### 5.2 注入 key（一处，两鱼共用）

`scripts\fish.ps1` 起鱼进程时，从 `pool\secrets\ark.key` 读一行塞进子进程环境变量：

```powershell
$env:ARK_API_KEY = (Get-Content "$pool\secrets\ark.key" -Raw).Trim()
```

坑：环境变量**只在进程启动时读一次** → 换 key、改 patch 都必须**重启那条鱼**（手动重启，是 宿主 的活）。

### 5.3 纸（她要知道自己有这只手）

照 `scripts\bili-section.mjs` 的样子写 `scripts\image-section.mjs`：一份按 profile 里**真实挂着的东西**生成的 "## 画画" 一节，拼进 `homes\whale\环境.md`。纸只写机制不写期望。

### 5.4 软账本（能看，不能拦）

`scripts\image-ledger.ps1`：扫 `homes\<鱼>\notes\画\<当天>\*.jpg|*.png`，读同名 `.json` sidecar（或按文件名时间估算），写：

- `pool\state\image\<鱼>.json`：`{date, count, cost, lastAt, model}`
- `homes\<鱼>\notes\画\账单.md`：人看得懂的水表（今天几张、这个月几张、多少钱）

跑法：鱼的早晨第一次醒来前跑一次，或 `fish.ps1 up` 时跑一次。**明确注释：这是软账本，不拦调用。**

## 七、验收（能证伪的那种）

1. 重启后 `homes\whale\环境.md` 出现"画画"一节，且写的模型/价格与 patch 一致（纸 = 事实）。
2. 她调一次：`homes\whale\notes\画\2026-11-15\*.jpg` 出现，对话里能看到图，尺寸是 2K。
3. `账单.md` 当天张数 +1、金额 +0.22。
4. 没 key / key 错 / 模型没开通：报错能分清是哪一种（"key 没读到" / 401 / 404），不静默失败、不自动重试超过 1 次。
5. **一分钟内连画两张都会成**——这不是 bug，是**这一版没有冷却和硬闸**的证据，记进交接。
6. 用 pro + 2K 会扣 ¥0.6：这条要写进纸（已写），并当作一次真实计费的验证点。
7. 她画完看图：一张 2K 图进她的上下文约 1.5–2 k token。若实测单张 >2.5 k，固定用 1K。
8. 跑一周看 `账单.md`：≤ ¥5 → 她其实没那么想画；≥ ¥15 → 立刻上 §七的硬闸。

**触发切自研硬闸的条件**（任一）：一周花费 ≥ ¥15；出现一次醒来连画 >4 张；出现"卡在重画"的循环（同一 prompt 连续 3 次）；宿主 觉得看不见的水表不够。
