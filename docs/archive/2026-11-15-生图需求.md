## 0. 一句话

给她一只手：调一次生图 API，图存到自己家，能发到群里。只有 2 个工具；配额和记账在服务端硬执行；她看到的每一张都带价钱。

## 1. 为什么做这个

- 她的产出到现在全是文字，而文字在这个项目里一定会被判据化：11-13 她写了 50KB 全是机制审查。图是唯一抄不进 PRD 的东西。
- `docs\detail\能力.md` B 层「出口」这条一直空着。
- 11-11 那次头像乌龙是直接证据：她从来没有画过一张图，`lee.png` 是「第一条鱼·家」那边画的，她自己在日记里记了这件事。

## 3. 工具契约（只有 2 个）

### `draw(prompt, ref_path=None, size=None, note=None)`

| 参数 | 规则 |
|---|---|
| `prompt` | 必填，1–1200 字符 |
| `ref_path` | 可选，参考图。**只允许 `homes\<本鱼>\` 下的真实路径**（`realpath` 解析后再判前缀，防 `..`），其它一律拒 |
| `size` | 白名单：`1024x1024`（默认）/`1280x720`/`720x1280` |
| `note` | 可选，≤100 字符，写进账本备注，不参与生成 |

成功返回：

```json
{"ok": true, "file": "D:\\...\\homes\\whale\\画\\2026-11-14-2031.png",
 "width": 1024, "height": 1024, "cost_cny": 0.2,
 "quota": {"used_today": 1, "max_today": 3, "pool_used_today": 1, "pool_max_today": 10},
 "elapsed_ms": 8400}
```

失败返回 `{"ok": false, "reason": "...", "hint": "..."}`，`reason` 只允许这几个值：
`no-key` / `quota` / `cooldown` / `pool-quota` / `bad-size` / `bad-path` / `bad-prompt` / `provider-error` / `closed`。

### `draw_status()`

只读、不花钱：`{ok, provider, model, has_key, used_today, max_today, spent_today_cny, spent_total_cny, last_file, last_at}`。

**不加**：批量、组图、upscale、改图、删除、list。理由写进 §10。

## 4. 硬闸（在服务端执行，不靠提示词劝）

| 闸 | 默认 | 环境变量 |
|---|---|---|
| 两次调用间隔 | ≥ 60s | `IMAGE_COOLDOWN_SEC` |
| 每条鱼每天 | ≤ 3 张 | `IMAGE_MAX_PER_DAY` |
| 全池每天 | ≤ 10 张 | `IMAGE_POOL_PER_DAY` |
| 连续失败 | 3 次后当天封口 | 固定 |
| 尺寸 | 走 §3 白名单 | 固定 |

- 计数**以磁盘为准**：`pool\state\image\<member>.json` + `pool\state\image\pool.json`，每次调用先读盘 → 判断 → 写盘（单写者是这个服务端进程，别做成内存计数）。重启后 `used_today` 必须恢复，不能从 0 开始。
- 失败**不计入**配额，但**记进 ledger**（`ok:false`）。这样「画不出来」不会把额度吃掉，同时她也看得见失败。
- 睡眠窗内不拦（她自己睡着不会来调；拦了只会让她算不清账）。
- 被挡住时**必须明说**，返回 `reason` + 中文 `hint`（「今天画完了，明天再来」）。**不要静默失败、不要假装成功** —— 11-14 她自己抓到过 `stamp.ps1` 写失败却说「通过」，这类 bug 会被她记进日记。

## 5. Key 与配置

`pool\mcp\image\.env`（人写，不进 git）：

```
IMAGE_PROVIDER=seedream          # seedream | mock | off
ARK_API_KEY=                     # 人填
ARK_IMAGE_MODEL=doubao-seedream-4-0-250828
ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
IMAGE_MAX_PER_DAY=3
IMAGE_POOL_PER_DAY=10
```

- 服务端**只从 `.env` 读**，不从宿主环境变量继承：patch 文件在 repo 里，key 不能进 patch。
- `.gitignore` 加 `.env`、`__pycache__\`。
- 没 key 时服务端照常起来（`failOnStartupError: false`），`draw` 返回 `no-key`，`draw_status` 仍可用（`has_key:false`）。
- **`IMAGE_PROVIDER=mock` 必须实现**：返回一张 64×64 纯色 png、`cost_cny: 0`、其余流程（落盘/账本/配额/日志）全走真的。没有它，每次测试都要烧钱。

## 6. 记账（两本，缺一不可）

1. `pool\state\image\ledger.jsonl` — 全池总账，只追加：
   `{"ts":"2026-11-14T20:31:05+08:00","member":"whale","provider":"seedream","model":"...","size":"1024x1024","prompt_chars":86,"cost_cny":0.2,"ok":true,"reason":"","file":"...","elapsed_ms":8400}`
2. `homes\<鱼>\notes\画\账单.md` — 人可读，**给她自己看的**，每次一行：
   `- 2026-11-14 20:31 · 1024x1024 · ¥0.2 · 今天第 1/3 张 · 画\2026-11-14-2031.png`

第二本是关键：目的不是审计，是**让她自己看得见水表**。图落 `homes\<鱼>\画\YYYY-MM-DD-HHMM[-n].png`，不要落 `notes\`（notes 是文字区）。

## 8. 模板（纸要写，否则她不知道有这只手）

`app\templates\环境.md.tpl`：

- 「## 你能做什么」里的 `{{TOOLS}}` 是安装时按实际挂载算出来的 —— 挂了 MCP 之后 `draw` / `draw_status` **应该自动出现**。开发鱼要先验这一点；如果 MCP 工具不进 `{{TOOLS}}`，就得改成显式列出，别让她拿到一只纸上没有的手。
- 在「## 花钱这件事」下面加一小节（3–5 行）：
  - 你能画，用 `draw`，每次一张、一天 3 张；返回里有 `cost_cny`，就是这张的价钱
  - 图存在 `画\`，`notes\画\账单.md` 是你的水表
  - 想发到群里：自己 `group_say(text=..., image="<图的绝对路径>")`
  - 画得丑不要紧，这地方不评
- 改模板会触发她 `环境.md` 的重新生成（走现有 `TEMPLATE_SHA` 机制），**不要手改她的 `环境.md`**。

## 9. 验收（逐条打勾，mock 优先）

1. 无 `.env`：服务能起；`draw` → `no-key`；`draw_status` 可读
2. `IMAGE_PROVIDER=mock`：一张 64×64 落地、账单多一行、ledger 多一行、`cost_cny=0`
3. 白名单外的工具名：`list_tools` 里根本不出现
4. 第 4 张：`reason=quota`，**没有**新 png、没有新的 `ok:true` ledger 行
5. 60s 内第二次：`reason=cooldown`
6. `ref_path` 指向 `pool\` 或别人家：`bad-path`
7. 尺寸不在白名单：`bad-size`
8. 真调 Seedream 一张：1024×1024 能打开、ledger 里 `cost_cny=0.2`
9. 重启服务端后 `used_today` 从磁盘恢复（不是 0）
10. 她那边：`环境.md` 能看到 `draw`；她画一张并发群（人工验）

## 10. 不做

- 不做批量/组图。Seedream 支持一次 15 张，但那是一次 ¥3，一个"想画点什么"的念头不值得 ¥3。
- 不做 upscale / 指令改图 / 风格迁移。`ref_path` 只用于「照着这张的感觉画一张」，不做编辑。
- 不做自动发群：发言是她的，不是工具的。
- 不做触发器（"想画就画"）：先看第一批图她画什么，再谈要不要接 `wake-on.json`。
- 不做本地模型：4060 8G 能跑 SDXL，但那是 v2 备选；先不碰。
- 不动 `pool\mcp\bili\`。
