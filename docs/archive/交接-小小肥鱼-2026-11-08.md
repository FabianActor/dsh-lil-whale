## 4. 已验证的技术事实（可以直接用，别再重查）

环境：dsh `0.2.2-rc.1`，Node v26.8.1，`DSH_HOME=C:\Users\Fabian\.dsh`，GUI `http://127.0.0.1:3080`。
checkout 在 `C:\Users\Fabian\AppData\Roaming\npm\node_modules\@deepseek-ai\dsh`（下文 `AI/` = 它的 `node_modules\@deepseek-ai\`）。

1. **通道实测**（最重要）：
   ```powershell
   dsh --profile web --json "…"                                  # 新建会话，输出 {type:'session',sessionId}
   dsh --profile web --session-id <id> --json "…"                # 在同一段历史上再跑一个 turn
   ```
   事件流：`session` → `status(turn_start/step_start)` → `text` → `status(turn_end)` → `final{text}`；退出码 0/1。会话不存在会直接报错。
2. **preset** = 普通 plugin row：`@deepseek-ai/dsh-agent-preset` 的 `config:{id, plugins[], name?, description?, order?}`。id 落在 `SessionHeader.agentPreset`，**首轮之后不能再改**（`agent-preset/locked`）。preset 不是沙箱。
3. `@deepseek-ai/dsh-persona` 只能挂在 preset 里（全局挂会与 deployment persona 撞车）。字段 `prefix` / `suffix` / `complete` / `includeRuntimeContext`。
4. 关不掉的自动注入：`working-directory`（cwd 作为 required runtime context）。`harness-dev-context` 可被 `includeRuntimeContext:false` 抑制。`~/.dsh/memory/` **不是**自动注入源（只在 Leea 自己 AGENTS.md 的正文里）。
5. skills 目录的 `dshHome` 可配 ⇒ 她的技能可以指向她自己的目录。
6. **profile patch 吃 insert，preset 就是这么挂的**（2026-11-08 深夜已验）：往 `C:\Users\Fabian\.dsh\profiles\web\cordis.patch.yml` 追加一个 `- insert:` 块，`dsh --profile web --dump-config` 输出里就出现 `# == C:\Users\Fabian\.dsh\profiles\web\cordis.patch.yml` 与 `- id: preset-lil-whale`（行 1498）。**早先「insert 不生效」只对 M-1 那个探针插件成立**——它是靠 `package.json` 依赖装进来的，包名才是那条路；`@deepseek-ai/dsh-agent-preset` 本来就在 web-app bundle 里，profile 行能解析到，所以能挂。另一条通道仍然有效：`dsh.profile.bundles` + 包自带 `dsh.bundle.patch`（形状照抄 `dsh-better-sidebar`），将来把 preset 打进可分享 bundle 走这条。`--dump-config` 只证明**配置合成**，不证明**注册表激活**（子插件解析、persona 挂载）——后者要重启后在新会话预设选择器里看。
7. **cordis 两条坑**：模块级 `export const inject = ['x']` 会让插件永不 apply；**读未 inject 的服务属性会抛错**（`cannot get property "x" without inject`），诊断代码自己就能把插件搞死。
8. HTTP 打不了宿主：`POST http://127.0.0.1:3080/api/*` → 401 unauthorized。
9. schedule：`target` 有 `session` / `new_once`（预留 id，首次投递创建后复用）/ `new`；模型侧工具 `schedule_create(title,prompt,rrule,target)` **不暴露 create**，两种新建目标都会保存编辑者的 cwd 与 preset。存储 `$DSH_HOME/storages/schedule.json`；宿主必须运行才能投递。
10. Web 设置页/新会话选择器**能选自定义 preset**（`@deepseek-ai/dsh-client-ui-agent-preset`）；创建/修改引导到创造模式。
