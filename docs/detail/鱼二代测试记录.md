1. **安装层没在家根补"当前用户完全控制"**——她第一次调用 pwsh 就撞 `SetNamedSecurityInfoW failed (Win32 5)`，自己跑诊断 skill 修好了。修法：`install.ps1` 加 Step 3d，`acl-check/acl-repair` 与 `doctor` 同步（CHANGELOG r136 / A.105）。
2. **名册拒绝文案把宿主的活派给鱼**——`group_say` 原先教她"把这段会话的 id 写进 pins.json 就行"。修法：改指向 `fish.ps1 bind`（CHANGELOG r136 / A.104）。
3. **干净装机的 patch 撞 YAML 空列表**——新 profile 的 `cordis.patch.yml` 末尾是 `[]`，追加 `- id:` 变成两个文档，`--dump-config` 直接失败。修法：`seed-child-profile.mjs` 有 `[]` 就替换（CHANGELOG r138）。

另：她的首条唤醒词已按预登记自验（`resumed` 没过档，逐字相同）；`first` 也拿到了第一份真实样本（见 D2）。

还有一个诊断小坑（r140 已修）：`fish.ps1` 拉起鱼时 `DSH_PROFILE` 会从调用方环境继承，boot 行写着 `"profile":"web"`——实际生效的是 `--profile` 参数，功能没错，但诊断行会误导。现在起鱼时显式设置 `DSH_PROFILE`。
