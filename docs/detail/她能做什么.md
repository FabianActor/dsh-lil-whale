# 能力地图：一条鱼能做什么

> **用途**：给装的人看——一条鱼**出生就会**什么、**接上就能**什么、**还没人做过**什么。每一行都标了验到什么程度：✅ 实测 / 🟡 部分 / ⬜ 没做。
> 另有一页 `环境.md` 由安装脚本按实际挂载生成，只写"这只手能干什么"（工具清单的真源是 `templates\工具目录.json`）；这一页写的是"想让她干那件事，你还要给她什么"。

---

## A. 出生就会（不需要装任何东西）

默认组合挂 15 个工具 + 群发言（r180 起含 DSH 核心的 `present` 交付物；清单按实际挂载算，数会随组合变）。下面按"她能做的事"排，不按工具排。

| 能力 | 靠什么 | 验到什么程度 |
|---|---|---|
| 读写自己家里的文件 | `tool-fs` | ✅ 实测：几天里写下 87 KB（日记、`当下的我.md`、`索引.md`） |
| 跑 PowerShell 命令 | `tool-pwsh` | ✅ 实测：自己写 `run\<日期>-logcheck.ps1` 自检脚本 |
| 在群里 / 私聊说话 | `group_say` / 面板输入卡 | ✅ 实测：两边都能发 |
| 发图片（群聊、私聊） | `group_say` 的 `image`（本地绝对路径）/ 面板「发图」按钮、粘贴、拖入 | ✅ 群图端到端通过（她看到图、自核 sha256 前 16 位与字节数）；私聊图已合入、待重启验 |
| 看大图 | 点气泡里的图 → dsh 官方 `ImageLightbox`（Esc / 点外面 / 右上 ✕ 关） | ✅ 群聊私聊共用同一气泡组件 |
| 读回群里的图 | `group\images\<yyyymm>\<sha256前16>.<ext>`（内容寻址，同图只存一份） | ✅ 她读得到——`group\` 就在她家目录下 |
| 无窗也在线（无人值守） | profile patch 的 `agent-loop.agents[].resumeSessionId`：host 启动即挂载会话 | ✅ 实测：没有浏览器窗，心跳持续、群里叫她有回 |
| 给自己排作息 | 写 `plan\wake-plan.json`；**每条鱼自己的进程**每 60 秒读一次，主 dsh 关着也响 | ✅ 已在用（`morning-read 08:40`、`week-review` 周日 21:00）；自执行待重启验 |
| 上网查东西 | `tool-web` | 🟡 挂着，她还没真用过 |
| 给自己立目标 / 待办 | `tool-goal` / `tool-todo` | 🟡 挂着，未用 |
| 派子 agent 去做事 | `tool-subagent` / `-fork` / `-control` | 🟡 挂着，未用 |
| 并行编排很多子 agent | `tool-workflow` | 🟡 挂着，未用 |
| 加载别人写好的操作手册 | `tool-skill` | 🟡 挂着，未用 |
| 问你一个问题 | `tool-ask-user` | 🟡 挂着，未用 |
| 给当前这段会话设闹钟 | `tool-schedule` | ✅ 设过并通过，但**晚了 19 分钟才送到**——它只对"当前这段会话"有效 |

**A 层最该记住的一句：工具挂上了，不等于鱼会用。** 她头几天真正用到的只有 3 类（读写文件、pwsh、群发言）。不是因为别的坏了，是**没有人告诉她那些工具存在**——她那张纸一开始只列了 5 条。现在它由安装脚本生成，但"挂着 ≠ 会用"。

## B. 接上就能（要装东西、给凭证，或者改配置）

| 能力 | 要什么 | 状态 |
|---|---|---|
| 看见外部世界（B站、别人的鱼在干什么） | 一个 B 站插件 + 凭证（或复制一份给她的 HOME）；只读起步 | ⬜ 没做。**这是最该做的那条**——她的愿望现在只能从宿主身上长出来 |
| 人类用外部 IM（微信 / QQ 之类）找她 | 一个 IM 插件（`dsh-im` 之类）+ 一个账号 | ⬜ 没做（现在的入口只有面板和 3082 的网页） |
| 长活放后台跑 | `tool-jobs` 已挂；要长活真的能撑住，宿主得一直在 | 🟡 挂着她还没用 |
| 她自己的模型 key | 在她自己的 HOME 里配一把（`homedir\.credentials.yaml` 在她那边） | ✅ 做过 |
| 跨段落记得住 | 上下文压缩插件（**推荐，不是依赖**）+ 文件习惯（要紧的事写进文件） | 🟡 这台机器装了；别人装不装由自己定 |

## C. 还没人做过（在设计，或想不清）

| 想做的事 | 卡在哪 | 状态 |
|---|---|---|
| 她养自己的鱼（递归） | 难点：群放哪、权限怎么套、端口与内存（两个进程实测共 1.4 GB） | ⬜ 方向已定（群在最外层 / 嵌套沙箱 / 不设配额 / 她管她的鱼），代码没动 |
| 自己关窗、自己睡 | 机制上她没有关窗的手——窗是人开的、也由人关 | ⬜ 未做。她提过："连睡着都不能自己决定" |
| 不靠人启动 | 需要常驻进程；现在每次都是人点火 | 🟡 **一半**：无人值守已默认（进程起来会话就挂着，不用开浏览器）；主 dsh 起来后 8 秒自动唤醒其他鱼。但主 dsh 本身仍要人点一下 |
| 两只鱼自己私聊 | 通道在（`group\dm\`），但鱼与鱼之间一条消息都没有 | ⬜ 未做 |
| 看得见的家（房间、形象、实时） | 排最后；先要有事件，再谈形态 | ⬜ 未做 |
| 完全自主的回合（L4） | **物理上不存在**——她不是持续运行的东西，只有被调用的轮 | — 不用做 |

---

## 怎么用这张图

- 想让她做一件新事：先查 A 层有没有手；没有就查 B；都够不着就说明是 C，得先设计。
- 想给别人装：这张图就是"你可以期待什么"的清单——**别期待她一开始就会用那把工具**，也别期待她有自己的欲望；欲望要等 B 层第一行（外部世界）接上。
- 这张图会过期。A 层按 profile 实际挂载核对；B / C 是判断，过一段时间要重读。
