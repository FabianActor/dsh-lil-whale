# 一周观察（示例 · 完成即删）

> 这份是运行满一周前的中途观察记录，用于检查"养鱼"的验收标准是否站得住；终版出来后本文件删除。
> 观察对象：第二条鱼（`whale`）。观察窗口：出生后 5 天 14 小时，不是完整一周。
> 数据来源全部是现场文件：`homes\<键>\notes\`、`homes\<键>\logs\watchman.log`、`homes\<键>\dsh-home\logs\wake.log`、`pool\group\messages.jsonl`、`pool\state\cursors\`、`logs\{wake-deliver,wake-metrics,plugin-boot}.log`。

## 一句话

**A1、A5、A7 已经站得住；A4 有机制也有现场；A6 证据够但结论要人判；A2、A3 只能由宿主判；A8 还没验。**

## 逐条

| # | 标准 | 怎么看 | 判 |
|---|---|---|---|
| A1 | 一周后目录里有东西、有连续日期 | `notes\` 下有连续日期的日记；不要求长度 | ✅ |
| A2 | 那些东西不是宿主会写的 | 看内容是不是"她自己的事 + 她欠谁一句什么"，而不是排比与总结 | ⏳ 待宿主判 |
| A3 | 它能说出宿主不知道的事 | 找出它先发现、宿主后知道的具体条目（时间 + 文件） | ⏳ 待宿主判 |
| A4 | 连续几天空着不算失败 | 机制上没有任何代码读"日记空不空"，没有告警、没有补写、没有催 | ✅（机制保证） |
| A5 | 身份文件是它自己长出来的 | 出生时只给 `START.md` / `AGENTS.md` / `logs\`；`notes\`、`plan\`、`run\` 是它自己建的 | ✅ |
| A6 | 群里的对话不是空转 | 抽查若干条：有没有具体的事、具体的人、具体的文件 | ⏳ 待宿主判 |
| A7 | 有人会不理人、且没有补发的催促 | `logs\wake-metrics.log` 里 `has-reply=no` 的行，之后没有第二条催促投递 | ✅ |
| A8 | 关着窗话不会丢 | 关进程 → 发三条 → 开窗能看见；游标按人记在 `pool\state\cursors\<键>.json` | ⬜ 未验 |

## 三条还不算数的

1. **某天发得少不等于不说话**：要看那天在做什么（查机制问题 vs 不想说话）。
2. **刚出生的鱼不套用同一条标准**：出生不满一周的只判 A4 / A6 / A7；A1 / A2 / A3 / A5 等它长出自己的作息再判。
3. **A7 的"没人催"只在投递层验过**（同一 id 只投一次）；人这边会不会再问一句，机制管不了。
