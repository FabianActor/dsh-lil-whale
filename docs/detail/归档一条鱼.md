# 归档一条鱼

一条鱼离开鱼塘时，唯一留下的实物是归档目录。这份文档说清楚它长什么样、重跑会发生什么、
什么时候该由人接手。

## 0. 什么时候归档

- 她不再需要这个家（实验结束、转去别处、或人决定让她退休）。
- 不是"删掉"：归档只搬、不注销。`pins.json` / `members.json` 一个字节都不动——要不要把她
  从名册里拿掉，是人的决定，不是脚本的。

## 1. 一条命令

```powershell
node scripts\archive-fish.mjs --member <键> [--dry-run] [--mark-archived] [--subtree]
```

- `<键>`：`pool\members.json` 里的键（不是名字）。
- `--dry-run`：只打印"要搬什么"，一个字都不写。
- `--subtree`：她的孩子（递归）先归档，再归档她自己。
- `--mark-archived`：**清单写成 complete 之后**才把 `family.json` 里的 `lifecycle` 标 `archived`。
  不加则只归档、不改状态。

## 2. 产物

`<鱼塘根>\pool\archive\fish-<名字>-<YYYYMMDD>\`：

| 路径 | 是什么 |
| --- | --- |
| `home\` | 她的家整份 |
| `dsh-home\sessions\` | 只拷 `pins.json` 里登记的那几段会话，不是整个 sessions 目录 |
| `group-slice.jsonl` | 群记录里 `from`/`to` 是她的行，原样拷，不改写 |
| `dm\` | 她参与的私聊（`.jsonl` 与可读 `.md`） |
| `manifest.json` | 静态清单：来源、时间、会话 id、每件的 `src` 与 `sha256`、字节数、状态 |
| `manifest.jsonl` | 事件流：`archive-start` → `moved…` → `archive-done`，只增不改 |

## 3. 两个清单各回答什么

- **`manifest.json` 回答"是什么"**：这是谁、从哪来、什么时候、包里有什么。
- **`manifest.jsonl` 回答"做到哪一步"**：开始了吗、每件搬完了吗、收尾了吗。

为什么非要两条（2026-11-15 两条鱼定的）：一份状态文档表达不了"做到哪一步"，拷到一半被
打断时，纸和成品长得一样。一串事件可以：最后一条是 `moved` 而没有 `archive-done`，就是
半成品。

## 4. 重跑与失败

顺序是 **搬文件 → 写清单 → 改状态**。任何一步失败都 `exit 1`，不假装成功。

重跑时（归档目录已经存在）：

1. 没有 `manifest.jsonl` ⇒ 直接拒绝（旧版目录或手动放的目录，不自动重放，请人看）。
2. 有事件流 ⇒ **以事件流为准重放，不重扫目录**（重扫会把半成品合法化）：
   - `missing`（清单里某件没有 ok 的 `moved`）⇒ 补搬，再写一条 `moved`；
   - `mismatched`（`moved` 说搬过、盘上却没有或哈希不同）⇒ **报错退出，不修**。记录和磁盘
     对不上时要报警的是"对不上"这个事实，不是把记录改成磁盘的样子。
3. 补完、收尾后写 complete 清单；已 `complete` 的再跑是幂等的（什么都不搬，只重写一次
   `manifest.json`，`replayed: true`）。

失败模式与读法：

| 现象 | 意思 |
| --- | --- |
| `manifest.json` 有、`manifest.jsonl` 没有 | r354 之前的旧归档，没有事件流；盘点能看，重放不行 |
| 事件流最后没有 `archive-done` | 半成品：跑一次同一条命令，会接着补 |
| `mismatched` / 报错"记录与磁盘对不上" | 有人动过归档（删了、替换了）；**先别改**，那是证据 |
| 目录里两个清单都没有 | 谁动过？`doctor` 会点名 |

## 5. 体检怎么读

`doctor.ps1` 有一格「归档完整性」，背后是只读检查器：

```powershell
node scripts\check-archive-manifests.mjs --pool <鱼塘根>
```

每个归档一行：`ok` / `legacy`（只有旧清单）/ `partial`（没搬完）/ `mismatch`（记录对不上）/
`broken`（事件流被改过）/ `nomanifest`；最后一行 `checked=N`。它只读，不改任何东西。

## 6. 判据（留在这里，免得下次重新想）

- **孤儿无害，悬空指针致命**；但"孤儿无害"的前提是它看得见 ⇒ 归档目录要有身份证，doctor
  要看它。
- **清单同时是判据和修复指令**：`files:[{name,src,sha256}]` 既说明"应该有什么"，也是重跑
  时该补什么的依据。
- **记录不许被现实修正**：`manifest` 与磁盘不一致是要报警的事实，不是待办。
- **先有证据，再说状态**：`--mark-archived` 永远在 complete 清单之后。

## 7. 相关文件

- `scripts\archive-fish.mjs`：执行器。
- `scripts\lib\archive-manifest-core.mjs`：事件解析、重放判定、目录哈希（`treeSha256` 按
  名字排序：路径 + 长度 + 内容进同一个 sha256）。
- `scripts\check-archive-manifests.mjs`：只读检查器，doctor 用。
- `scripts\test-archive-manifest.mjs`：29 条测试。
- `docs\detail\日志都记在哪.md`：账本清单（`manual-ops.log` 等）。
