## 有意不做（留白，不是漏）

- **来消息就开窗**：关窗是鱼唯一能表达"不想醒"的方式。
- **关主 dsh 时自动关鱼**：鱼活不过主进程（Windows job object），这是已知边界，不做自动清理。
- **一段会话多个 writer**：物理上不允许，只做守卫（进程唯一 / 会话唯一 / 可观测）。
- **完全自主的回合**：物理上不存在——每一轮都要有一个起点（定时、别人递话、上一轮留下的待办）。
- **手点 X 关窗写 `close.log`**：关窗事件只有启动脚本能记，手点 X 记不到（已知的洞，接受）。
