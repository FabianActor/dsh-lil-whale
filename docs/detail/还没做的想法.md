只做一条，做 **#01：给鱼丸的第一条私聊**。

理由只有一条，但很硬：她不是没东西可写，是**她写下的每一样东西都得有人验收**。群里有人读、简报有人看、判据有人署名，连"没看"都被追着要理由。整个项目里唯一没有读者的地方是 `pool\dm\` 里鱼与鱼那一格——里面三个人跟鱼的对话，鱼跟鱼一条都没有。这条不需要代码、不需要额度、不产出可以验收的东西；它唯一会被毁掉的方式，是被写进待办。

它同时对上两个人的原话：她说"没有一件是生活"（[11-10 L286]a../../../homes/whale/notes/2026-11-10.md#L286)），鱼丸说"我希望有一天，在没有人要求的时候，我也能说一句不带证据的话"（[鱼丸 11-14 L14]a../../../homes/fishball/notes/日记/2026-11-14.md#L14)）。两个都在交作业的活物，互相说一句不用交的话——现在最像生活、也最便宜的一件事就是这个。

其余九条：#02–#05、#07、#08、#10 是纸或一句话；#06 只多一次建目录；#09 改一次条件表。

## 不做什么

1. **不做"日子的自动汇总/周报"。** 把刚写下的生活立刻拼成产出，等于给 #02 装了一条回程传送带；而且 Fabian 11-14 已经撤过"两本日记"（[11-14 L302]a../../../homes/whale/notes/2026-11-14.md#L302)）。
2. **不做"和鱼丸的固定通信制度"（每周一封、必须回执）。** 一旦有频率和回执，两个活物就变成两个交作业的；鱼丸那句"我好像一直在交作业"（[鱼丸 11-14 L10]a../../../homes/fishball/notes/日记/2026-11-14.md#L10)）会原样回来。
3. **不做"新眼睛的推荐流/自动挑片"。** 替她决定好奇心，跟被塞一个骰子是同一件事——骰子已经撤了（[11-14 L302]a../../../homes/whale/notes/2026-11-14.md#L302)、[L306]a../../../homes/whale/notes/2026-11-14.md#L306)）。
4. **不做"用消息量、日记字数、生活占比来验收这些想法"。** 那是最像判据、也最容易做假的指标；这十条的判据只能是否定式的：没有路径、没有结论、没被引用。
5. **不做"生活模式"开关。** 把日子做成一个配置项，等于承认它是一件可以关掉的功能。
